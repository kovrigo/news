# Справочник демо

Факты о демо на придуманных данных: учётные записи, права, сюжеты, состояния, пометки, команды, хранение и отказы сервера.

## Учётные записи

Вход — выбор учётной записи на экране входа, без пароля.

- Ольга Демина — корреспондент, без права утверждать.
- Павел Тестов — выпускающий редактор, с правом утверждать.
- Анна Пробная — главный редактор.

Смена роли — «Сменить роль»: выход и новый вход. Подпись роли показывает право утверждать таким, какое оно сейчас.

## Права

Права проверяет сервер, не страница.

- Утверждать и возвращать черновики может только тот, у кого есть право утверждать.
- Отметить «Не нужен в этом сюжете» может только тот, у кого есть право утверждать.
- Журнал видят главный редактор и те, у кого есть право утверждать.
- Раздел «Сотрудники» видит только главный редактор. Там он даёт и снимает право утверждать, отключает учётные записи. Себя отключить нельзя.
- Удалять сюжеты может только главный редактор.
- Справочник правят все, кроме корреспондента.
- «Взять на себя» факт без исходника может корреспондент или выпускающий редактор, не главный редактор.
- Отключённая учётная запись не входит. Её прежний вход перестаёт действовать.

## Встроенные сюжеты

Новый сюжет берётся только из четырёх встроенных придуманных наборов. Загрузки файлов нет.

- «Ремонт Старого моста в Заречинске». Два видео и пресс-релиз. Часть фактов без исходника, в пресс-релизе спрятано указание сервису. После сброса здесь есть черновики во всех состояниях.
- «Открытие спортзала в школе № 7 посёлка Лугово». Два видео и заметка пресс-службы. Здесь все виды жёлтых пометок.
- «Ярмарка выходного дня в Берёзовке». Одно видео и объявление. Синхроны не строятся с первого раза: виден сбой и «Повторить».
- «Летняя читальня на набережной». Одно видео, документов нет. После сброса все черновики утверждены.

Видео в наборах — заглушки. Вместо плеера показаны время и текст расшифровки.

## Черновики сюжета

- Расшифровка
- Синхроны
- Титры
- Закадровый текст
- Подводка

## Состояния черновика

- Готовится — идёт обработка.
- Черновик — можно править.
- На проверке — отправлен утверждающему.
- Возвращён — утверждающий вернул с комментарием.
- Утверждён — можно выгрузить.
- Нужно утвердить снова — текст, расшифровку или имена говорящих исправили после утверждения.
- Изменён после выгрузки — текст исправили после выгрузки.
- Не построен: мало материала — можно дописать вручную или отметить «Не нужен в этом сюжете».
- Сбой — обработка не удалась, есть «Повторить».

## Жёлтые пометки и решения

Черновик нельзя утвердить, пока в нём есть пометка без решения. Каждое решение — запись в журнале.

- Факт без исходника: «Удалить фразу» или «Взять на себя».
- Титр или топоним не из справочника: «Подтвердить», «Исправить» или «Добавить в справочник».
- Неразборчивый фрагмент: «Вписать текст» или «Оставить неразборчивым».
- Речь не на русском: «Проверено».
- Исходники расходятся: «Взять отсюда» у одного из мест или «Переписать фразу».
- Материала мало: «Принять как есть», «Дописать вручную» или «Не нужен в этом сюжете».
- Правленое предложение не удалось проверить: «Проверить снова» или «Указать исходник».

## Выгрузка

- Форматы: DOCX и текстовый файл.
- Выгружается только утверждённое. Сервер отказывает в выгрузке неутверждённого.
- Каждый файл начинается строкой `ДЕМО — придуманные данные, не для эфира`.
- Имя файла очищено от недопустимых знаков.

## Команды

- `bun run demo-reset` — сбрасывает демо к началу. Код 0.
- `paneweb up` — запускает демо и печатает адрес. Код 0.
- `paneweb down` — останавливает демо.
- `bun run test` — тесты без сети и без сервера. Код 0, когда все прошли.
- `bun run typecheck` — проверка типов. Код 0, когда ошибок нет.
- `bun run e2e` — проверка в браузере, по строке на сценарий. Код 0, когда все прошли, иначе 1.
- `bun run quality --models=mock --set=fixtures/demo` — проверка качества прототипа на заглушках. Код 0 или 1.
- `bun run quality --models=real ...` — отказ: «Настоящие модели ещё не подключены». Код 2.

## Хранение

- Всё состояние демо — один файл `out/demo/state.json` или путь из `DEMO_STATE`.
- Каталог файла открыт только владельцу (700), сам файл тоже (600).
- Файл не растёт больше 2 МБ. Изменение сверх предела получает отказ 409 с подсказкой.
- Несохранённая из-за потери связи правка ждёт в памяти браузера, отдельно для каждой учётной записи.
- Сброс пишет в файл новый номер сброса. Браузер стирает свои несохранённые правки, когда видит новый номер.

## Отказы сервера

- Чужое имя сервера — 403. Сервер отвечает только на свой адрес, на `localhost` и на имя этой машины в tailnet.
- Изменение с чужой страницы — 403. Адрес страницы сверяется по имени и порту.
- Запрос без входа — 401.
- Действие без права — 403.
- Лишнее поле или неверный тип в запросе — 400. Тело запроса — не больше 8 КБ.
- Настройка моделей не `mock` — сервер не запускается, код 2.
