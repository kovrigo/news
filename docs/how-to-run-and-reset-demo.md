# Как запустить, сбросить и остановить демо

Для того, кто ведёт демо на машине разработчика. Нужен Bun и средство запуска серверов `paneweb`.

## Запустить

```
bun install
bun run demo-reset
paneweb up
```

- `paneweb up` печатает адрес демо. Откройте его в браузере.
- Сервер слушает только адрес этой машины. Порт выдаёт `paneweb`.
- Не запускайте сервер руками через `bun run dev`. Без порта от `paneweb` он не стартует и выходит с кодом 2.

Если `paneweb up` закончился с кодом 1 и словами «FAILED to start», повторите команду. Изредка запуск совпадает с уборкой старых серверов на машине.

## Сбросить к началу

```
bun run demo-reset
```

- Команда печатает `Демо сброшено: out/demo/state.json` и выходит с кодом 0.
- Файл демо заменяется исходным придуманным состоянием: четыре сюжета, три учётные записи, справочник.
- Всё введённое руками удаляется из файла.
- Браузер, который откроет демо после сброса, сначала стирает свои несохранённые правки.

Сбрасывайте демо после каждого показа. Перезапуск сервера при этом не нужен.

## Остановить

```
paneweb down
```

## Показать демо коллеге по ссылке доски

- Доска открывает демо по имени этой машины в tailnet. Ссылка работает только внутри tailnet. В интернете демо недоступно.
- Если сервер перезапустить, пока ссылка доски жива, демо встанет на другой порт. Прежний порт держит прокси доски.
- После такого перезапуска возьмите новый порт из вывода `paneweb up` и переставьте ссылку доски на него.

## Если демо не открывается

- «Демо работает только на заглушках: MODELS=… не поддерживается». Уберите настройку `MODELS` или поставьте `MODELS=mock`. Другого режима нет.
- Сервер просит `bun run demo-reset`. Файла демо ещё нет: выполните сброс.
- Правка не сохраняется, демо просит удалить сюжеты или сделать сброс. Файл демо дошёл до предела 2 МБ. Удалите лишние сюжеты за главного редактора или сделайте сброс.
- Страница открылась, но вместо экрана входа «Это действие вам недоступно». Демо открыто по чужому имени сервера. Откройте адрес, который напечатал `paneweb up`, или ссылку доски.

## Проверить демо после изменений

```
bun run typecheck
bun run test
bun run e2e
```

- Все три выходят с кодом 0, когда всё в порядке.
- `bun run e2e` сам сбрасывает демо до и после проверки. Ему нужен запущенный `paneweb up`.
