# Test

Проверка 1 октября 2026 года. Локальное демо на встроенных придуманных сюжетах, в браузере, как пользователь.

## Итог

Демо работает от начала до конца на всех трёх ролях. Найдено 8 дефектов. Один серьёзный: по ссылке с доски сайт не открывался. Все 8 исправлены. Последний проверен заголовками прокси доски, а в браузере через адрес доски пока не проверен: см. «Ссылка с доски».

Оценка состояния: 90 из 100 до исправлений, 100 после. Последняя цифра станет окончательной после проверки в браузере по ссылке с доски.

К выпуску готово только демо. Это не продукт для редакций: настоящих моделей, загрузки файлов, входа по паролю и сети редакции нет.

## Что проверено

- Роли: вход за каждую из трёх, разделы в меню у каждой роли, прямые ссылки на закрытые разделы.
- Обработка: новый сюжет из набора, ход обработки, сбой черновика и «Повторить».
- Исходники: нажатие на факт показывает место в видео или документе.
- Ручной выбор: «Указать исходник» и выбор абзаца в документе, «Дописать вручную» для непостроенного черновика.
- Правки: правка предложения, «Сохранено», перепроверка исходника, предупреждение перед правкой утверждённого черновика.
- Утверждение: запрет при пометках без решения и у возвращённого черновика, утверждение, повторное утверждение после правки.
- Возврат: пустой комментарий не принимается, комментарий виден корреспонденту.
- Журнал: записи всех действий, фильтры по сюжету, сотруднику, действию и «Взяли на себя без исходника».
- Выгрузка: DOCX и текстовый файл, неутверждённое не выгружается, признак «Изменён после выгрузки».
- Права: главный редактор снимает и даёт право утверждать.
- Удаление: сюжет пропадает из списка, его адрес отвечает «Сюжет не найден», в журнале остаётся запись.
- Сброс: демо возвращается к встроенным сюжетам.
- Сервер отказывает напрямую: утверждение без права, выгрузка неутверждённого, удаление не главным редактором, раздел сотрудников не главному редактору, список без входа.

## Исправлено

- Подпись роли не менялась вместе с правом. Павел без права оставался «выпускающий редактор, право утверждать». Теперь подпись показывает право таким, какое оно сейчас: в шапке, на экране входа и в списке сотрудников.
- Журнал и раздел сотрудников, открытые по прямой ссылке без доступа, вечно показывали «Загрузка…». Теперь страница пишет «Это действие вам недоступно».
- Непостроенный черновик предлагал корреспонденту отметить, что черновик не нужен. Такой кнопки у корреспондента нет. Теперь это предложение видят только те, у кого есть право утверждать.
- В окне возврата было «Комментарий для Ольга Демина». Теперь «Комментарий корреспонденту: Ольга Демина».
- В фильтре журнала два сюжета с одинаковым названием было не различить. Так бывает, если дважды взять один набор. Теперь у одноимённых сюжетов в фильтре указано время загрузки. У остальных название без изменений.
- «Дописать вручную» снимало пометку «Материала мало» без записи в журнале. Теперь в журнале одна запись «Принял(а) как есть — дописано вручную». Правка по-прежнему пишется одной записью «Правил(а)», без повторов.
- На экране нового сюжета кружок выбора у длинного описания сжимался. Теперь все кружки и флажки 18 на 18 точек на широком и на телефонном экране.

Каждое исправление проверено в браузере после перезапуска сервера. Для подписи роли, фильтра журнала и записи о решении добавлены тесты.

## Ссылка с доски

По ссылке с доски новый посетитель видел «Это действие вам недоступно» вместо экрана входа.

- Доска открывает сайт по имени этой машины в tailnet, через прокси на 127.0.0.1.
- Прокси передаёт серверу имя машины с портом и `Origin` с https.
- Демо защищалось от чужих сайтов и отвечало только на 127.0.0.1 и localhost. Поэтому весь API отвечал 403, начиная с `GET /api/session`.
- В браузере через адрес доски это воспроизвелось на широком и телефонном экранах: страница 200, `GET /api/session` 403, экрана входа нет.

Что изменено:

- Скрипт запуска paneweb передаёт серверу одно имя — имя этой машины в tailnet. Сам код демо по-прежнему не запускает процессов.
- Сервер отвечает на 127.0.0.1, localhost и это имя. На любое другое имя — 403, как раньше.
- Изменения принимаются, только если `Origin` совпадает с адресом по имени и порту. За прокси страница открыта по https, а запрос приходит по http, поэтому схема не сравнивается. Страница с другого порта той же машины получает 403.
- Cookie входа прежняя: HttpOnly, SameSite=Strict.

Проверка:

- Одноразовый приёмник на 127.0.0.1:21435 принял запрос прокси доски. Заголовки: `Host: grieving-orange.tail9feca9.ts.net:21435`, `Origin: https://grieving-orange.tail9feca9.ts.net:21435`, `X-Forwarded-Proto: https`.
- Запущенный сервер с этими заголовками отвечает так: страница 200, `GET /api/session` 200, вход 200 с cookie, список сюжетов с cookie 200.
- Тем же сервером отказано: чужое имя — 403, чужой `Origin` — 403, `Origin` с другого порта этой машины — 403.

Порт сайта сменился с 21435 на 21436. Для исправления сервер пришлось перезапустить. Порт 21435 на адресе tailnet держит прокси доски, поэтому paneweb выбрал следующий свободный. Прежняя ссылка доски ведёт на 21435 и сейчас отвечает 502. Пройти путь в браузере через адрес доски можно только после того, как ссылку переставят на 21436.

## Сбой первого запуска сервера

Это не дефект демо. Это гонка в средстве запуска серверов на этой машине.

- Средство запуска ждёт 2 секунды и только потом записывает номер процесса сервера.
- Уборщик просыпается раз в минуту. В эти 2 секунды он видит сервер без номера процесса и считает его брошенным.
- В 18:27:38 уборщик записал в свой журнал «reap news--task-work-3--d8eb33: no live process (stale instance)» и остановил только что запущенный сервер.
- Сервер к этому моменту уже напечатал свой адрес, то есть запустился. В журнале сервера после адреса стоит «terminated by signal SIGTERM».
- Запуск закончился с кодом выхода 1 и словами «FAILED to start». Повтор в 18:27:52 прошёл с кодом 0.
- Пробный проход уборщика во время запуска воспроизводит гонку без вреда: «would reap news--task-work-3--d8eb33: no live process (stale instance)». Сразу после запуска тот же проход сервер уже не трогает.
- Три холодных запуска подряд: остановка, сброс демо, запуск. Все три с кодом 0, страница отвечает 200.

Средство запуска лежит вне этого репозитория, поэтому здесь его не меняли.

## Остаточные риски

- Обработка, исходники и проверка фактов идут через заглушки. Качество настоящих моделей здесь не проверено.
- Запуск сервера изредка обрывается, если совпадёт с проходом уборщика. Повторный запуск помогает.
- Пока ссылка доски жива, любой перезапуск сервера уводит его на другой порт: прежний порт держит прокси доски. После перезапуска ссылку надо переставлять.
- Браузерные проверки раньше изредка падали без понятной причины: 2 раза из 17. В этот раз прошли все.
- Проверял один человек за раз. Одновременную работу нескольких людей не проверяли.
- Только Chromium. Safari и Firefox не проверяли.
