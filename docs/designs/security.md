# Безопасность демо

Проверка 1 октября 2026 года. Проверена вся ветка демо относительно основной.

## Статус демо

Демо — локальный прототип на придуманных данных. Модели в нём только заглушки. Для настоящих материалов, настоящих сотрудников и открытого доступа оно не готово. Разработка продукта для редакций не начата.

## Найдено и исправлено

- Удаление сюжета оставляло в журнале введённый текст: комментарий возврата, причины решений, старое и новое имя говорящего, текст из справочника. Brief и окно удаления обещают другое: в журнале остаются только кто, что и когда.
- Теперь удаление стирает у строк этого сюжета и текст факта, и пояснение. Тест проверяет журнал и файл состояния. Без исправления тест падает.

Других подтверждённых уязвимостей нет.

## Что держит код

Каждый пункт проверен тестом, запросом к запущенному демо или чтением кода.

- Новый сюжет берётся только из четырёх встроенных придуманных наборов. Загрузки файлов нет.
- Обработка идёт только через заглушки. Если настройка просит не заглушку, демо не запускается. Скрипт проверки качества с настоящими моделями тоже отказывается.
- Сервер слушает только адрес этой машины. Запрос с чужим именем сервера получает отказ. Так закрыт обход через подмену адреса чужим сайтом.
- Изменения принимаются только со страницы самого демо. Запрос с чужой страницы получает отказ. Отметка входа не отправляется с запросами с чужих сайтов.
- Каждый запрос проверяется по строгой схеме: лишнее поле или неверный тип — отказ. Тело запроса не больше 8 КБ, файл состояния не растёт больше 2 МБ.
- Права проверяет сервер, не страница. Утверждать и возвращать может только тот, у кого есть право утверждать. Удалять сюжеты и менять права может только главный редактор. Журнал видят главный редактор и утверждающие. Справочник не правит корреспондент.
- Отключённая учётная запись не входит, её прежняя отметка входа не действует.
- Выгружается только утверждённое. В файле есть пометка демо. Имя файла очищено от недопустимых знаков. Знаки, ломающие DOCX, из введённого текста убираются.
- Текст на страницах выводится как текст, не как разметка.
- Ключей и паролей в истории ветки нет. У зависимостей известных уязвимостей нет.

## Чего код не держит

- Код не может запретить ввод настоящего текста. В демо руками вводят правки черновиков, комментарии к возврату, причины, имена говорящих, записи справочника. Программа не отличает придуманный текст от настоящего и не фильтрует его.
- Защита здесь — правило и надпись на каждом экране и в выгрузке: «Демо на придуманных данных. Не загружайте и не вставляйте настоящие материалы».

## Остаточные риски

- Пароля нет. Любой человек или программа на этой машине может открыть демо под любой учётной записью, в том числе главного редактора. Роли защищают от ошибки, не от человека.
- Файл состояния с введённым текстом могут прочитать другие учётные записи этой машины.
- Выгруженные файлы уходят из демо. Сброс и удаление сюжета их не стирают.
- Браузер, который больше не открывает демо, хранит несохранённую правку, пока его память не очистят.
- Сброс заменяет файл состояния, но не затирает диск. Старые данные могут остаться на диске и в копиях машины.
- Название удалённого сюжета остаётся в журнале. Оно берётся из встроенного придуманного набора, не вводится руками.
- Защита от встраивания страницы в чужой сайт не включена. Сейчас это не опасно: отметка входа не передаётся внутрь чужого сайта. До открытого доступа её нужно включить.

## До открытого доступа

Всё это входит в «Проверку до разработки» из Brief:

- вход по паролю и приглашения;
- хранение и удаление в сроки юриста, резервные копии;
- настоящие модели и поставщики;
- рабочая среда.

Проверка выполнена моделью. Она не заменяет проверку специалистами по безопасности.
