# Changelog

## 2026-10-02 — демо на придуманных данных

Теперь можно пройти весь путь пакета черновиков одного сюжета, за три роли, без настоящих материалов. Демо работает на машине разработчика и только на заглушках. Как пройти его в первый раз, сказано в документе «Первый проход по демо».

### Что можно сделать

- Войти корреспондентом, выпускающим редактором или главным редактором. Пароля нет, роль меняется кнопкой «Сменить роль».
- Начать новый сюжет из четырёх встроенных придуманных наборов и смотреть ход обработки, сбой и «Повторить».
- Нажать на факт в черновике и увидеть его место в видео или документе.
- Решать жёлтые пометки: факт без исходника, титр не из справочника, неразборчивая речь, речь не на русском, расхождение исходников, мало материала.
- Править черновик, отправлять на проверку, утверждать, возвращать с комментарием, утверждать повторно после правки.
- Выгрузить утверждённое в DOCX или текстовый файл. Неутверждённое не выгружается, каждый файл помечен как демо.
- Смотреть журнал с фильтрами, давать и снимать право утверждать, править справочник, удалять сюжет.
- Сбросить демо к началу одной командой: `bun run demo-reset`.

### Границы

- Настоящие материалы, учётные записи редакций, платные модели и подключение каналов не допускаются до юридической, пользовательской и технической проверок. Объяснение — в документе «Границы демо и почему они такие».
- Загрузки файлов нет. Если настройка просит не заглушку, демо не запускается.
- Демо открывается только на этой машине и по ссылке доски внутри tailnet. Открытого адреса в интернете нет.

### Защита

- Сервер отвечает только своему адресу и имени машины в tailnet. Изменения принимаются только со страницы самого демо.
- Права проверяет сервер. Файл демо и его каталог открыты только владельцу.
- Удаление сюжета стирает введённый текст и из журнала: остаются только кто, что и когда.

### Для разработчиков

- Ядро прототипа: проверка фактов и чисел по исходнику, схемы черновиков, заглушки распознавания речи и модели, сценарий качества `bun run quality`.
- Проверки: `bun run typecheck`, `bun run test` (192 теста), `bun run e2e` (8 сценариев в браузере).
- Документы: «Первый проход по демо», «Как запустить, сбросить и остановить демо», «Справочник демо», «Границы демо и почему они такие».
